# Changelog

All notable changes to this project will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/) for public releases.

## [1.0.0] - 2026-10-03

### Added

- Document-first knowledge graph editing in a standalone HTML application.
- Direct node and relationship selection/editing on the graph.
- Create, update, and delete nodes, relationships, node types, and relation types.
- Undo/redo history.
- Search, relation filtering, zoom, pan, fit, and node navigation.
- Graph validation with Graph Health status.
- Duplicate and compatibility checks for Viewer JSON.
- Lossless `.kge.json` project format with document metadata and node positions.
- Strict five-field Viewer JSON export.
- Complete graph SVG export.
- Custom in-app dialogs and right-click context menus.
- Direct relationship creation via connect mode and Shift-drag.
- Offline/local-first operation with no runtime dependencies.
