# Support

## Questions and usage help

For usage questions, open a GitHub Discussion if Discussions are enabled for the repository. Otherwise, open an issue and choose the closest available template.

## Bugs

Use the Bug Report issue template. A minimal JSON file that reproduces the issue is especially helpful.

## Feature ideas

Use the Feature Request template and describe the workflow or user problem the feature would improve.

## Security

Do not use public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
